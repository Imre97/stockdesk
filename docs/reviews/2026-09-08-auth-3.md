## Findings

### Blockers

- `apps/api/src/modules/auth/repository.ts:84-86` — `deleteMany({ where: { tokenHash } })` has no `revokedAt: null` predicate, so it deletes rotated rows too, not just the live session being logged out. Probe result: register → `/refresh` (old row now `revokedAt` set) → `POST /logout` with the **old** cookie → `204`, then `/refresh` with that old cookie returns `{"error":{"code":"UNAUTHORIZED","message":"Refresh token is missing, unknown or expired."}}` instead of `REFRESH_REUSED`, and the successor session still refreshes (`200`). An attacker holding a stolen refresh cookie can rotate it, then call the unauthenticated `/logout` with the original value to delete the evidence, and the victim's next silent refresh is a benign 401 that never revokes the attacker's session — the exact escalation AC5 exists to trigger. This is not implied by the accepted decision ("logout deletes the presented row"): only live rows need deleting. Fix: `deleteMany({ where: { tokenHash, revokedAt: null } })` (all four existing logout tests keep passing) plus a test asserting rotate → logout with the old value → `/refresh` with the old value is `401 REFRESH_REUSED` and the successor is dead.

### Should fix

- `packages/shared/src/api-error.ts:13` — `API_ERROR_CODES` / `ApiErrorCode` have no production consumer; the producers `apps/api/src/app.ts:67` and `apps/api/src/middleware/error-handler.ts:31` still pass bare string literals, so drift between the union and the emitted codes is caught only by `not-found.test.ts:14`, never by the compiler. Type the code parameter (`AppError`, `envelope`) as `AuthErrorCode | ApiErrorCode`.
- `packages/shared/src/api-error.test.ts:74-78` — tautological: asserts an `as const` literal array contains its own literals, zero behavioral signal. Replace with an assertion tied to emitted output, or delete it and keep only the `not-found.test.ts` membership check plus an equivalent one in `error-handler.test.ts:56`.

### Nice to have

- `docs/modules/auth.md:50` — the new logout row states the outcome for the presented live token but not for an already-rotated one; after the blocker fix add the clause that only non-revoked rows are deleted and revoked rows are retained for reuse detection.
