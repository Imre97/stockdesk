## Findings

### Blockers

### Should fix

- `apps/api/src/modules/auth/repository.ts:84-89` with `:113-118` — `/logout` only sets `revokedAt`, so one retried silent refresh with the logged-out cookie hits the reuse path and revokes **every** live token of that user, logging the account out on all other devices; `apps/api/test/auth.logout.test.ts:32-33` asserts only `status === 401` and hides this. Spec (`docs/modules/auth.md:50`) describes logout as per-token. Two defensible fixes (delete the row on logout, or exempt logout-revoked rows from the escalation) — per CLAUDE.md rule 10 this is a user decision; then assert the resulting code in the logout test.
- `apps/api/src/app.ts:67` — the app emits `NOT_FOUND` (404), which is listed neither in `docs/modules/auth.md:68` nor in `AUTH_ERROR_CODES` (`packages/shared/src/auth.ts:45-52`), while `docs/02-conventions.md:93` requires every code to be listed in the module spec. Add `NOT_FOUND` (404) to the spec's error-code line, and to the shared union if the client is meant to switch on it.

### Nice to have

- `apps/api/src/app.ts:56` — `trust proxy` is set unconditionally, so in any deployment or local run without a proxy in front the client controls `X-Forwarded-For` and gets a fresh rate-limit bucket per request. Read the hop count from the config module (default 0, 1 in production) so the setting matches the actual topology.
- `apps/api/src/modules/auth/repository.ts:106,118,123` — three `as RotationResult` casts defeat return-type checking inside the transaction. Annotate the callback (`async (tx): Promise<RotationResult> =>`) and drop the casts.
- `apps/api/src/server.ts:22-24` — the boot pruning line has no test because `server.ts` starts listening on import. Extract it into a `runBootTasks()` in a testable module and assert it deletes expired rows.
- `eslint.config.js:125-131` — the test override disables `no-restricted-syntax` as well as `no-restricted-imports`, so test files may do `parseFloat`/`toFixed` money math; the accepted decision covered only `no-restricted-imports`. Narrow the override.
- `apps/api/src/lib/config.ts:71` — `resetConfigCache()` still has no caller and no test (TD-9 remains open).

## Optimization opportunities

- `apps/api/src/modules/auth/repository.ts:126` — every successful rotation awaits an extra `DELETE` round trip in the request path; on a cold Neon compute that is added latency on the one endpoint the SPA calls at every page load. Prune at boot plus on a low-frequency schedule (or fire-and-forget the delete) instead of on each rotation; expected gain one round trip per refresh. Next module.
- `apps/api/test/auth.refresh.test.ts:55-76` — the race test registers a user at bcrypt cost 12 in each of 5 iterations (10 hashes plus 5 truncations); 2 iterations give the same signal at roughly 60 % less suite time. Later.
- `apps/api/src/app.ts:59` — `express.json()` at the 100 kb default for bodies of three short strings (TD-6). Later.
- `apps/web/src/i18n/index.ts` — both locale catalogs statically in the main chunk (TD-5). Next module that adds a namespace.
