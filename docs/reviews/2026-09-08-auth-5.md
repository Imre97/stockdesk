### Should fix

- `scripts/check-language.mjs:37` — repo mode uses bare `git ls-files`, so untracked files are invisible. Probe: a new `docs/probe-untracked.md` containing a Hungarian stop word gave `Language check passed`, exit 0; the same file staged gave exit 1. Local `npm run lint` therefore green-lights brand-new non-English files until they are added. Use `git ls-files --cached --others --exclude-standard`.
- `apps/api/test/boot.test.ts:29` — the prune job is now the only delete path for token rows, but no test asserts the L-9 invariant on it: a revoked, unexpired row must survive. Add a third row with `revokedAt` set and `expiresAt` in the future and assert it is still there after `runBootTasks`.
- `apps/api/src/lib/config.ts:17` — `TRUST_PROXY_HOPS` defaults to `0`, so a production deploy that does not set it silently degrades the auth rate limit to one shared bucket keyed on Render's proxy socket address (the exact L-7 failure, now reachable by omission instead of by code). `render.yaml` sets `1`, but nothing enforces it: fail fast or report when `isProduction && trustProxyHops === 0`.

### Nice to have

- `apps/api/src/boot.ts:30` — `reportError("Pruning expired refresh tokens failed.")` drops the cause; on Neon a boot-time prune failure gives no reason and the next attempt is 60 minutes away. Include the error message.
- `apps/api/src/server.ts:16` — `void runBootTasks(config)` has no `.catch`; harmless today only because every throw path is inside `pruneOnce`. Attach a catch so a future boot task cannot produce an unhandled rejection.
- `apps/api/test/check-language.test.ts:13` — `const ASCII_STOP_WORD = "hib" + "a";` obfuscates a fixture purely to dodge the checker scanning this file; a `\u` escape (as used on line 11) is consistent with the rest of the file.
- `apps/api/test/check-language.test.ts:22` — `mkdtempSync` roots are never removed, so each run leaves temp trees behind. Clean up in `afterEach`.

## Optimization opportunities

- `scripts/check-language.mjs:104` — reads and scans every tracked file on every `npm run lint`; on a repo this size it is negligible, but once fixtures grow, restrict to changed files in the pre-commit path and keep the full scan in CI (later).
- `scripts/check-language.mjs:23` — the stop-word regex can match inside slash-separated ASCII blobs, so base64 or path fixtures could false-positive; require at least one adjacent whitespace or quote if that ever fires (later).
